# 🎮 Neon Dodge

A neon-themed browser game built using **HTML, CSS, and JavaScript**.

## ✨ Features

- 🏀 Falling neon balls
- 🧺 Basket movement using Arrow Keys
- ⭐ Score system
- ❤️ Lives system
- ⏱️ 60-second timer
- 💥 Collision detection
- 🔄 Play Again functionality
- 🌈 Neon glowing UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Click **PLAY** to start the game.
2. Use **⬅️ Left Arrow** and **➡️ Right Arrow** to move the basket.
3. Catch the falling balls in the basket.
4. Every successful catch increases your score.
5. If you miss a ball, you lose a life.
6. The game ends when all lives are lost or the timer reaches zero.
